# LandPage.Veterinaria.Mobile

🐾 Site Veterinário - Dra.Thayssa_Galvão
Projeto de uma interface web completa para clínicas veterinárias, focado em facilitar o contato entre tutores e a clínica, com um design moderno e limpo.

🚀 Funcionalidades
Interface Responsiva: Adaptado para dispositivos móveis e desktop.

Seção de Serviços: Listagem de consultas, exames e vacinação.

Formulário de Contato: Sistema funcional (ou protótipo) para agendamento de consultas.

Galeria/Sobre: Espaço para apresentação da equipe e infraestrutura.

🛠 Tecnologias Utilizadas
HTML5 (Estruturação semântica)

CSS3 (Estilização e Flexbox/Grid)

JavaScript (Interatividade e validação de formulários)
